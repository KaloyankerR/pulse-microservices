# Analyse

This folder contains supporting evidence documents related to analysis activities in the Pulse microservices project, including requirements analysis, risk assessment, threat modeling, and performance analysis.

## Contents

- **Non-Functional-Requirements-Specification.md**: Comprehensive specification of non-functional requirements (NFRs) including performance, scalability, availability, security, and reliability requirements
- **OWASP-Top-10-Risk-Assessment.md**: Detailed assessment of OWASP Top 10 security risks and mitigation strategies
- **Performance-Testing-Results.md**: Results and analysis of performance testing, validating system meets <200ms response time requirement
- **Polyglot-Persistence.md**: Analysis and documentation of polyglot persistence strategy, database selection rationale, and data consistency patterns
- **Threat-Modeling-Documentation.md**: Comprehensive threat modeling using STRIDE methodology, identifying threats and mitigation strategies

## Purpose

These documents demonstrate:
- Requirements analysis and specification
- Security risk assessment and threat modeling
- Performance analysis and validation
- Technology selection analysis
- Data storage strategy analysis
