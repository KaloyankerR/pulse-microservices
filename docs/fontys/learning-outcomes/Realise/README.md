# Realise

This folder contains supporting evidence documents related to the realization and implementation of the Pulse microservices project, including CI/CD pipelines, deployments, migrations, and implementation details.

## Contents

- **Auth-User-Data-Migration.md**: Documentation of the data migration process when separating auth service from user service
- **CI-CD-Pipeline.md**: Implementation documentation of the CI/CD pipeline using GitHub Actions
- **GDPR-Compliance-Implementation.md**: Implementation of GDPR compliance measures including user rights and data protection
- **Kubernetes Initial Deployment.md**: Documentation of the initial Kubernetes deployment process
- **Load-Testing-Automation.md**: Implementation of automated load testing using k6 and Apache JMeter
- **Moderator-Security-Enforcement.md**: Implementation of moderator security features and enforcement mechanisms

## Purpose

These documents demonstrate:
- Implementation of CI/CD pipelines
- Deployment processes and automation
- Data migration and synchronization
- Compliance implementation (GDPR)
- Testing automation and implementation
- Security feature implementation
