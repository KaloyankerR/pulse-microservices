# Professional Standard & Personal Leadership

This folder contains supporting evidence documents related to professional standards and personal leadership demonstrated in the Pulse microservices project.

## Contents

### Professional Standard (LO1)
- **Auth-Service-Separation.md**: Documentation of the decision and process to separate authentication into its own microservice
- **DOT-Framework-Research-Process.md**: Comprehensive documentation of the DOT framework application across multiple technology and architecture decisions
- **Microservices-Architecture-Decision.md**: Architecture decision record documenting the choice of microservices architecture pattern

### Personal Leadership (LO2)
- **Goal-Setting-and-Tracking.md**: Documentation of learning goals, tracking, and achievement throughout the project
- **Service-Split-Coordination.md**: Documentation of the coordination and leadership in service separation decisions

## Purpose

These documents demonstrate:
- Professional research methodology (DOT framework)
- Professional decision-making and documentation
- Personal leadership through goal setting and achievement
- Self-directed learning and initiative
- Professional communication and coordination

## Related Learning Outcomes

- **LO1**: Professional Standard
- **LO2**: Personal Leadership
